About Activity Log

The activity log provides a complete audit trail of all actions performed in the control plane.

Logged Actions:
  • Create: New users, clients, applications, environments, configs, flags, or OAuth providers
  • Update: Modifications to existing resources
  • Delete: Removal of resources
  • Toggle: Activate/deactivate actions for clients, flags, and providers
  • Login/Logout: User authentication events
Information Tracked:
  • Timestamp: Exact time of action
  • User: Email of user who performed the action
  • IP Address: Source IP for security auditing
  • Details: Additional context (JSON encoded)

This log is readonly and cannot be modified or deleted to ensure audit trail integrity.
